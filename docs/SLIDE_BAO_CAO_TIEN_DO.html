1. Tổng Quan & Bối Cảnh Thực Tiễn Problem Statement

Thách thức phân phối phần mềm Linux và rủi ro an ninh container truyền thống
⚖️ Hai Thái Cực Phân Phối Linux

Trong hạ tầng MLOps hiện đại, việc lựa chọn bản phân phối Linux mang tính quyết định đến hiệu năng và độ ổn định:

  • Arch Linux (Rolling Release): Luôn tiếp cận nhân Linux Kernel mới nhất (Kernel 6.x/7.x), cgroups v2 và nftables tối tân; triết lý "The Arch Way" siêu tinh gọn (chỉ ~400MB RAM).
  • Ubuntu Server (LTS): Độ ổn định doanh nghiệp, đóng băng phiên bản gói (Version Freeze) chu kỳ 5 năm, nhưng đi kèm sự nặng nề của các dịch vụ ngầm (snapd, cloud-init).
🚨 Hiểm Họa Docker Mặc Định (Root Daemon)

Đại đa số hệ thống hiện nay triển khai Docker daemon chạy dưới quyền root (UID 0):

  • Lập trình viên vô tư thêm user vào nhóm docker hoặc mount /var/run/docker.sock.
  • Container Escape: Lỗ hổng trong ứng dụng (RCE) cho phép hacker thoát rào chiếm toàn quyền kiểm soát máy chủ host (CVE-2019-5736).
  • Không phân đoạn mạng: Cơ sở dữ liệu thường xuyên bị mở cổng public 5432 dẫn tới nguy cơ đánh cắp dữ liệu hàng loạt.

2. Mục Tiêu Nghiên Cứu Đề Tài SMART Goals

Cam kết hoàn thành 5 mục tiêu kỹ thuật then chốt chuẩn công nghiệp
⚙️ 1. Tự Động Hóa IaC
Xây dựng 100% kịch bản tự động hóa bằng Bash script tuân thủ tính Idempotent và bắt buộc có kịch bản Rollback khôi phục nguyên trạng máy chủ khi có sự cố.
🛡️ 2. Rootless Isolation
Tiên phong hiện thực hóa Rootless Docker unprivileged trên Arch Linux qua User Namespaces và cgroups v2 delegation, triệt tiêu hoàn toàn rủi ro Container Escape.
🔒 3. Mạng Zero-Trust
Thiết kế phân tách 2 mạng Docker: Giấu kín hoàn toàn cơ sở dữ liệu PostgreSQL (5432) và MinIO API (9000) trong mạng nội bộ cô lập internal: true.
⚡ 4. AI Serving & CLI
Đóng gói vi dịch vụ AI OCR siêu nhẹ bằng FastAPI + Tesseract (Non-root UID 10001); phát triển công cụ dòng lệnh Terminal tương tác ai_cli.sh mã màu ANSI.
📊 5. Benchmark Đối Kháng
Đo lường định lượng mức tiêu thụ RAM tĩnh/động và kiểm thử tải trọng (RPS, Latency p50/p95/p99) đối kháng trực tiếp giữa Arch Linux và Ubuntu Server.
📑 6. Báo Cáo Học Thuật
Xuất bản báo cáo khoa học 82 trang chuẩn VKU (DOCX & PDF) trình bày chi tiết cơ sở lý thuyết nhân Linux, thiết kế hệ thống và số liệu thực nghiệm.

4. Đột Phá: Rootless Docker Engine Core Security

Vận hành trọn vẹn cụm container dưới quyền tài khoản không đặc quyền (Non-Root)
🔑 Cơ Chế Hoạt Động (User Namespaces)
  • Thiết lập cấu hình ánh xạ: /etc/subuid và /etc/subgid cấp cho user mlops 65,536 UID ảo bắt đầu từ 100000.
  • Tiến trình trong container: Tưởng mình là UID 0 (root ảo), nhưng nhân Linux chỉ gán UID 1003 hoặc 110000 trên host vật lý.
  • cgroups v2 Delegation: Cho phép user session tự điều phối hạn mức tài nguyên qua /etc/systemd/system/user@.service.d/delegate.conf.
  • Systemd Lingering: Kích hoạt loginctl enable-linger mlops đảm bảo container chạy ngầm 24/7 kể cả khi logout.
🛡️ Thử Nghiệm Tấn Công Container Escape
[Host Ubuntu - Rootful Docker]: $ docker run --rm -v /:/host alpine touch /host/etc/exploit -> File /etc/exploit TẠO THÀNH CÔNG! (Bị chiếm máy chủ) [Host Arch - Rootless Docker]: $ docker run --rm -v /:/host alpine touch /host/etc/exploit -> touch: /host/etc/exploit: Permission denied (CHẶN ĐỨNG!)

👉 Kết luận: Triệt tiêu 100% khả năng hacker can thiệp hay phá hoại hệ thống tệp của máy chủ vật lý.

5. Phân Đoạn Mạng Zero-Trust Network Isolation

Bảo vệ tuyệt đối cơ sở dữ liệu PostgreSQL và kho Artifact MinIO
📦 Cấu Hình Trong docker-compose.yml
# Định nghĩa 2 phân vùng mạng networks: mlops-frontend: { driver: bridge } mlops-backend: { internal: true } services: postgres: # Không bind ports ra host (0.0.0.0)! networks: [ mlops-backend ] mlflow: ports: [ "5000:5000" ] # Cầu nối: tham gia cả 2 mạng networks: [ mlops-frontend, mlops-backend ]
🧪 Kiểm Chứng An Ninh Chốt Chặn

Kiểm tra rò rỉ cổng từ máy chủ bên ngoài bằng lệnh nc (Netcat):

$ nc -z -v -w 1 localhost 5432 -> localhost [127.0.0.1] 5432: Connection refused $ nc -z -v -w 1 localhost 9000 -> localhost [127.0.0.1] 9000: Connection refused
  • Cơ sở dữ liệu hoàn toàn vô hình với bên ngoài.
  • MLflow vẫn kết nối CSDL bình thường qua hostname nội bộ postgres:5432.
  • Loại bỏ 100% rủi ro bị rà quét cổng và tấn công rò rỉ dữ liệu.

6. Gia Cố Host OS & Tường Lửa nftables Hardening

Bảo vệ vững chắc tầng hệ điều hành và tối ưu hóa tham số Linux Kernel
🔑 Hardening OpenSSH
  • Đổi cổng sang 2222 (né bot quét tự động).
  • PermitRootLogin no (Cấm root đăng nhập).
  • MaxAuthTries 3 (Chống brute-force).
  • Tắt X11 và TCP forwarding.
  • Vô hiệu hóa ssh.socket trên Ubuntu để kiểm soát chặt chẽ.
🛡️ Tường Lửa nftables
  • Chính sách Default Drop chuỗi INPUT.
  • Stateful connection tracking (established, related).
  • Meter Rate Limiting: Tối đa 4 kết nối/phút từ 1 IP:
    tcp dport 2222 meter ssh-meter { ip saddr limit rate over 4/minute } drop
⚡ Kernel Sysctl Tuning
  • net.core.somaxconn = 65535 (Tránh nghẽn socket queue).
  • net.ipv4.tcp_tw_reuse = 1 (Tái sử dụng nhanh TIME_WAIT).
  • net.ipv4.tcp_syncookies = 1 (Chống SYN Flood).
  • fs.file-max = 2097152 (Mở rộng file descriptors).

7. Vi Dịch Vụ AI OCR Serving Tối Ưu Microservice

Đóng gói Dockerfile Multi-Stage siêu nhẹ thực thi dưới quyền UID 10001
📦 Kỹ Thuật Đóng Gói Multi-Stage
  • Stage 1 (Builder): Cài đặt gcc, biên dịch các thư viện Python Pillow, pytesseract.
  • Stage 2 (Runtime): Chỉ copy thư viện đã build sang image sạch; loại bỏ hoàn toàn compilers giúp giảm kích thước và giảm bề mặt tấn công.
  • User Non-root 10001: Khởi tạo và chỉ định USER 10001 (tài khoản mlopsuser). Ứng dụng không bao giờ chạy quyền root.
  • Tích hợp endpoint kiểm tra sức khỏe /health và endpoint metrics /metrics.
